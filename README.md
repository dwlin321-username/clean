# 🧹 打掃小幫手

把「打掃整個家」拆成一個個小項目，自訂每天／每週要打掃的區域，降低開始打掃的門檻。

## 功能
- **今天**：顯示今天排定的打掃項目、預估時間、完成進度，以及需要準備的清潔用品
- **排程**：自訂「指定日期」、「每週幾」、「每天」要打掃哪個區域（或區域裡的部分項目），可指定負責人
- **區域**：區域 → 項目兩層結構，每個項目可設定預估時間、建議頻率、所需清潔用品、步驟說明
- **紀錄**：打掃熱度圖、連續天數、本月統計、尚未打掃／該打掃的項目、歷史紀錄（含備註）
- **設定**：家庭成員、清潔用品庫、一週起始日、匯出／還原備份

## 使用方式
1. 用 iPhone Safari 打開 GitHub Pages 網址
2. 分享 →「加入主畫面」
3. 資料存在手機瀏覽器（localStorage），建議每月到「設定」匯出備份

## 技術
純 HTML + CSS + JavaScript，不需安裝或建置。PWA（manifest + Service Worker）支援離線使用。

更新程式後，記得把 `sw.js` 裡的 `CACHE` 版本號 +1，手機才會更新到新版本。
